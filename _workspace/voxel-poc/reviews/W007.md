## Initial handoff — REJECT (resolved history)

The original handoff omits all benchmark unit/browser tests, explanatory metrics,
and final report template. Existing tests do not validate new behavior. Code
inspection identifies these blockers before standard measurement:

1. Two independent RAF loops sample old renderer metrics while the ordinary
   gameplay loop advances clamped dt. Resetting once per leg is insufficient for
   identical elapsed-time replay. Use one frame driver for both rendering and
   benchmark sampling, with train state derived from per-leg elapsed time.
2. Camera aspect is not normalized at start; input E/mouse remains active. DPR
   restoration uses raw devicePixelRatio rather than actual prior renderer DPR.
   Visibility cancellation waits for a RAF that may never run in a hidden tab;
   context loss is not handled. Restore immediately from event handlers and on
   failure/cancel/success, clear held keys, and restore mode/pose/marker/simulation.
3. mountMs is computed as residual wait duration, not measured mount time.
   Geometry bytes duplicate shared buffers, omit indices, and skip Baseline.
   Triangles/textures/programs are terminal values instead of sampled summaries.
4. Camera route is not three equal sample windows (5/10/15 seconds); diagnostic
   scaling similarly differs. Use sample-time thirds and an Overview warm-up.
5. Validator does not enforce full profile, durations/diagnostic consistency,
   indices, schema metrics, finite values, or conclusion. Threshold evaluator can
   return continue for duplicate modes/zero denominators/NaNs. Missing secondary
   and human acceptance must not yield an unqualified product continue.
6. Capture script times out after30 seconds during a210-second standard run,
   offers no profile/power input, lacks try/finally cleanup and output validation.
7. No tests for sampler boundaries/percentiles/schema/replay/order/thresholds,
   no production diagnostic download/cancel/restore test, no source/asset/bundle
   metrics script, and no final evidence template. Required checks are unfinished.

Root split correction into disjoint domain and runtime implementation scopes.
