# W003 Implementation Result

## Status

IMPLEMENTED

## Summary

Replaced the W001 tracer fixture with an immutable fixed Miniature Crossing Slice
Shared Scene Specification containing the approved semantic inventory, world
settings, bounds, camera markers, colliders, interaction ownership, palette
roles, animation bindings, and visual archetype variants. Added isolated
radius-160 planet math with circumference wrapping, a right-handed local
east/up/north basis, flat point and static geometry projection, separated
equatorial rail positioning using a north/south surface-arc gauge, and rigid
Object3D seating. Added shared Continuous Infrastructure
for the planet, curved road and footway, dense utility wires, and a closed
two-rail loop outside the renderer adapter root. Mode switching now disposes and
rebuilds only the adapter tracer while retaining the same scene object and
infrastructure.

## Acceptance Evidence

- Origin projects to `[0, 0, 0]` with center `[0, -160, 0]`; both physically
  separated equatorial rail lanes remain radius 160 from center, close exactly,
  and maintain the intended 1.5 m north/south surface-arc gauge. Circumference
  wrapping is tested at both signs and the seam.
- Surface basis vectors are unit length, pairwise orthogonal, and satisfy
  `east x up = north` at a representative slice coordinate.
- Static projection clones the BufferGeometry, preserves a custom attribute,
  recomputes normals and bounds, leaves the source unchanged, and produces only
  finite positions. The API documents that long geometry must be segmented by
  callers and performs no voxel-buffer subdivision.
- Rigid seating composes basis and supplied local rotation, preserves scale,
  and leaves child pivot transforms unchanged.
- Public scene validation rejects duplicate IDs, out-of-bounds entities,
  invalid collider dimensions, invalid interaction ownership, and missing camera
  markers. The fixture has one crossing, a two-car train variant, shop, two
  distinct houses, vending machine, relay box, poles/wires, fencing, four
  cherry trees, restrained petals, and a parked bicycle.
- Infrastructure tests prove one shared planet, road/footway set, stable closed
  two-rail loop, utility wires, and disposal boundary. The browser smoke test
  reads the infrastructure root's instance UUID and child-count attributes
  before and after mode switching; the exact UUID and count remain identical
  while only `renderer-adapter-root` is rebuilt.
- The shop has no interaction. Validator ownership permits only the vending
  machine's `dispense-drink` and relay box's `call-train` definitions.
- Both adapters continue to consume the same frozen `SAMPLE_SCENE`; adapter code
  defines no colliders, interactions, or simulation state.

## Assumptions or Deviations

- Flat `z / PLANET_RADIUS` is treated as latitude angular offset from the top
  point, preserving the requested top-origin tangent frame; the authored slice
  remains well within the valid local region.
- Continuous tracer tubes intentionally remain lightweight hybrid geometry;
  final content models, simulation, player movement, and Voxel Assets remain
  owned by later packages.

## Unresolved Risks

- Adapter tracer boxes remain authored in flat coordinates; later playable
  adapters own final projected content placement and functional behavior.
