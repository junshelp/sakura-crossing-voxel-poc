The fixture includes stable ground and marker entities and is passed by identity to both adapters. The unit test snapshots it before and after mounting. The browser test checks canvas visibility, Baseline Mode, Voxel Mode, and visibility after switching.

## Correction cycle 1 evidence

- Both adapters retain every created geometry and material and dispose each resource in `dispose()`. The contract test mounts an adapter, spies on the created mesh resources, and asserts each disposal is called once.
- `deepFreeze` recursively freezes fixture objects and arrays, including nested transforms, interactions, and benchmark markers. The fixture is typed directly as `SharedSceneSpecification` without an unsafe cast; nested immutability is asserted by the contract test.
- Removed unused `@vitejs/plugin-basic-ssl` from `package.json` and regenerated `package-lock.json` (clean install now reports 66 packages).
- Tightened `SharedSceneSpecification` so `seed`, `benchmarkCameraMarkers`, and the marker record are readonly at compile time; runtime assertions now cover the root and marker map freezes.

## Assumptions and risks

The tracer uses simple colored boxes and a wireframe distinction; later packages own production scene content. WebGL failure has a 2D canvas fallback so the smoke test remains meaningful in constrained browsers.

## Reviewer focus

Confirm the public contract is sufficient for downstream packages and that mode switching preserves fixture identity and scene state.
