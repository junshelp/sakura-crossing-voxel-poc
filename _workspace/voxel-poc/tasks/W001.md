# W001 Task — Executable Scaffold and Public Contracts

## Goal

Create the smallest strict TypeScript/Vite/Three.js application that builds,
tests, renders a visible tracer scene, and proves that Baseline Mode and Voxel
Mode consume the same Shared Scene Specification fixture.

## Required Behavior

- Use Node 20 or newer, strict TypeScript, Vite, Three.js, Vitest, and Playwright.
- Expose scripts for development, type checking, unit tests, production build,
  browser smoke testing, and a combined local check.
- Render a clearly non-blank tracer scene into one full-viewport canvas.
- Show a visible mode indicator and a control that switches between Baseline Mode
  and Voxel Mode.
- Define a public Shared Scene Specification contract containing stable entity
  identifiers, semantic kinds, transforms, colliders, interactions, palette
  roles, animation bindings, deterministic seed, and benchmark camera markers.
- Provide one deterministic sample fixture with at least a ground entity and one
  marker entity.
- Define one renderer-adapter interface and two placeholder implementations.
  Both must consume the exact same fixture object and create visibly distinct but
  equally simple tracer output.
- Switching mode must not recreate or mutate the fixture.
- Keep gameplay behavior outside renderer adapters and visual data.
- Add a CI workflow that installs, runs unit tests, type checks, and builds. The
  browser smoke test may be a separate job or command because browser installation
  is environment-specific.

## Acceptance Criteria

- `npm ci` succeeds from the generated lockfile.
- `npm test` passes deterministic contract and renderer-adapter tests.
- `npm run typecheck` passes in strict mode.
- `npm run build` succeeds and produces a production bundle.
- The Playwright smoke test asserts a visible canvas, initial Baseline Mode label,
  successful switch to Voxel Mode, and a still-visible canvas after switching.
- A source-level test or contract assertion proves both adapters receive the same
  fixture identity and do not mutate it.
- The application contains no final crossing content, train simulation, voxel
  compiler, or benchmark implementation.
