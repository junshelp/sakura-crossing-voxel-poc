# W002 Task — Voxel Asset Validator and Greedy Mesh Compiler

## Goal

Implement the browser-independent Voxel Asset validation, 32-cubed Voxel Chunk
partitioning, hidden-face removal, and deterministic Greedy Mesh compiler, with a
small Three.js BufferGeometry conversion at the adapter boundary.

## Required Behavior

- Export one canonical `VOXEL_SIZE` of 0.25 m and one `CHUNK_SIZE` of 32 cells.
- Accept unknown input through a runtime Voxel Asset validator. A valid asset has
  a stable id, a bounded named palette, and sparse integer-coordinate cells that
  reference palette ids.
- Palette entries explicitly classify surfaces as opaque, transparent, or
  emissive and carry deterministic color data.
- Reject non-object input, unknown top-level or nested keys, blank or duplicate
  ids, non-integer cell coordinates, duplicate occupancy, unknown palette ids,
  invalid colors or surface classes, and fields that attempt to embed gameplay
  behavior.
- Partition cells using floor division so negative coordinates map correctly.
- Resolve neighbor occupancy globally before meshing so two occupied cells across
  a chunk boundary never emit their shared internal faces.
- Emit a current-cell face only when its neighbor coordinate is empty. All
  occupied-to-occupied interfaces are internal regardless of palette class.
- Greedily merge adjacent coplanar exposed faces only when direction, palette id,
  and surface class are compatible.
- Produce deterministic, renderer-independent indexed buffers per Voxel Chunk and
  surface class. Include position, normal, palette/color data, indices, chunk
  coordinate, and bounds sufficient for culling.
- Convert one compiled surface group into Three.js BufferGeometry in a separate
  boundary module. The compiler itself must not import Three.js.
- Never create a Three.js Mesh in this package.

## Acceptance Criteria

- Empty assets produce no chunk meshes.
- A single voxel produces six outward quads with correct normals and winding.
- A solid rectangular volume produces only six merged exterior surfaces.
- A hollow volume exposes both outside and cavity surfaces without hidden faces.
- Adjacent different palette or surface-class voxels do not emit their shared
  occupied interface.
- Cells at coordinates 31 and 32 share no internal face despite belonging to
  different chunks.
- Negative coordinates partition and emit bounds correctly.
- Different input cell orderings produce byte-for-byte-equivalent logical output.
- Opaque, transparent, and emissive exterior faces enter their correct groups.
- BufferGeometry conversion exposes indexed position, normal, and palette/color
  attributes with computed bounds.
- Validator tests cover every required rejection category, including extra
  gameplay-like fields.
- Source search confirms there is no `new THREE.Mesh` or equivalent per-voxel
  construction.
